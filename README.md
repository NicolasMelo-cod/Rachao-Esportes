⚽ Rachão Esportes

Encontre partidas, conecte pessoas e entre em jogo.

O Rachão Esportes é um projeto em desenvolvimento com a proposta de facilitar a descoberta de partidas esportivas e aproximar pessoas que querem jogar. A ideia é reunir oportunidades para praticar futebol, vôlei e basquete, ajudando os usuários a encontrar jogos na sua região.

🚧 Status: em desenvolvimento. A primeira etapa contempla a Landing Page; as próximas funcionalidades serão implementadas ao longo da evolução do projeto.

🎯 Objetivo do projeto

Criar uma plataforma simples e intuitiva para que pessoas interessadas em praticar esportes possam encontrar partidas, conhecer outros jogadores e organizar sua participação.

🖥️ Primeira entrega: Landing Page

A etapa inicial é focada na interface de apresentação do produto, com conteúdo organizado para explicar a proposta do Rachão Esportes e orientar o usuário sobre o fluxo planejado:

Cadastre-se — criar uma conta na plataforma.

Escolha o esporte e o horário — encontrar uma partida de acordo com suas preferências.

Confirme e jogue — consultar as informações e se preparar para participar.

Esses passos representam a experiência proposta para a plataforma; a implementação das funcionalidades está em andamento.

🛠️ Tecnologias

Angular — framework utilizado na estrutura do Front-End.

TypeScript — linguagem utilizada no desenvolvimento Angular.

HTML5 — estruturação semântica do conteúdo.

CSS3 — estilização e composição visual da interface.

🚀 Como executar localmente

Pré-requisitos

Node.js instalado;

npm (incluído na instalação do Node.js);

Git para clonar o repositório.

Instalação

Clone este repositório:

git clone <URL_DO_REPOSITORIO>

Entre na pasta do projeto:

cd Rachao-Esportes

Instale as dependências:

npm install

Inicie o servidor de desenvolvimento:

npx ng serve

Acesse no navegador

O servidor de desenvolvimento recarrega a aplicação quando os arquivos são alterados.

🗺️ Próximas etapas

O escopo futuro do projeto prevê a evolução da Landing Page para uma aplicação com funcionalidades de descoberta e participação em partidas. Entre os pontos planejados estão:

Fluxo de cadastro e autenticação de usuários;

Busca e consulta de partidas;

Seleção de esporte, região e horário;

Detalhamento das partidas e confirmação de participação;

Evolução da aplicação para contemplar as demais camadas do projeto Full Stack.

Os itens acima são objetivos planejados e não significam que as funcionalidades já estejam disponíveis.
